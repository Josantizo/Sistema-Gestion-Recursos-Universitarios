
# Sistema-Gestion-Recursos-Universitarios
Sistema Web para gestión de recursos universitarios (Salones, Laboratorios, Salas de reunión, etc.)
El sistema web de Gestión de Recursos Universitarios permitirá a los estudiantes y a los docentes tener un mayor control sobre la reservación de recursos universitarios como laboratorios, salones y salón de reuniones, mediante resesrvaciones centralizadas en un calendario que les permitirá escoger el recurso universitario que desean ocupar, la fecha, hora en la que desean ocupar el recurso, curso, sección y docente, luego de realizar la reserva el sistema le enviará un correo al docente asignado para que pueda aprobar o rechar la solicitud de reserva, el sistema tendrá manejo de solapamientos de horarios para evitar confusiones en las reservas.
